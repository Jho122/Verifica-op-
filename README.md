# 🛠️ Ferramenta de Verificação  (Pj_Ferramenta)

Ferramenta desenvolvida em Python para automatizar tarefas de verificação, facilitando a gestão e monitorização de operações de rede e sistemas.

---

## 🚀 Funcionalidades
* Execução automatizada de rotinas de backup.
* Scripts dedicados à verificação de estado e infraestrutura.
* Interface e organização estruturada com suporte a estilos customizados.

---

## 📋 Pré-requisitos
Antes de executar a ferramenta, certifique-se de que tem instalado no seu ambiente:
* **Python 3.x** instalado.
* Dependências ou bibliotecas necessárias (caso utilize módulos específicos no script).
